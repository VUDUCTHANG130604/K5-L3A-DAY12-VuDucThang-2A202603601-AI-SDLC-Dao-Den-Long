# Đảo Đèn Lồng v1.0.0

Three islands, fuel/dawn survival, local persistent leaderboard, nine remappable actions and accessible settings. Contract1.3 preserves Phase3 gameplay.

Download dao-den-long-v1.0.0.zip, extract, enter its directory, run node scripts/serve.mjs with Node22+, open http://localhost:3000. No install/CDN. Check SHA256SUMS.txt. Bundle requires Node and a WebGL browser.

Validation:78 tests,33 deterministic CLI fixtures identical to Phase3, ten-night same-process soak0crashes/RSSgrowth about6%. Reference Windows/Intel Iris Xe:125.39avgFPS,66.64p1,1189.63msload. Instructor hardware/hidden tests unverified. Demo43seconds, silent actual browser recording.

Settings: browser localStorage. Scores: .data/leaderboard.json; back it up before replacing versions. README documents all commands; CHANGELOG covers four phases; CREDITS/LICENSE cover sources.
